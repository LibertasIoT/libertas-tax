# Casey Sample: a simple single return

**Synthetic test data. Never file these documents.** Every page is marked
"SYNTHETIC TEST DATA — NOT A TAX DOCUMENT". The name, address, EINs and SSN are
fictional.

Casey Sample is single, 41, lives in Florida and has no dependents. A whole
return in two papers:

| Paper | Form | What it says |
| --- | --- | --- |
| [casey-w2.pdf](casey-w2.pdf) | Form W-2 | $60,000 wages, $6,000 federal tax withheld |
| [casey-interest.pdf](casey-interest.pdf) | Form 1099-INT | $125.50 bank interest |

Try them in the
[U.S. tax return App](https://github.com/LibertasIoT/libertas-doc/blob/main/examples/federal-tax.md):
in the Document center, choose **Import with AI** and select both papers. In a
live test, AI read all 55 printed boxes exactly.
